# 15 — AI for Developers

AI tools are now part of everyday development, and interviews ask about them. Expect questions on how you use AI, how you use it safely, and how you would build AI features. This section prepares you for all three. It also covers MCP (Model Context Protocol) in practice: how to connect AI tools to Jira, GitHub, Slack and your own systems.

Like the React section, it is **interview-first**: concepts first, then questions with **what to say**, follow-up questions with answers, and common mistakes.

**Before this:** nothing special. Docs 04–06 assume you know [Node.js](../07-nodejs-backend/README.md) and [TypeScript](../03-typescript/README.md).
