# 04 — OOP, SOLID and Design Patterns

This section is about designing code that is easy to change. It covers the four pillars of object-oriented programming, composition vs inheritance, the SOLID principles, dependency injection, and the classic design patterns.

For every pattern you will see the problem it solves, how it looks in JavaScript/TypeScript, where it appears in real Angular and Node.js code, and **when not to use it**. Patterns used without a real problem only add complexity.

**Before this:** [02 — JavaScript](../02-javascript/README.md) (classes and prototypes) and [03 — TypeScript](../03-typescript/README.md) (interfaces and classes).
