# Cumulative assessments

## Gate A: language foundation

Prerequisites F01–F03 and JS01–JS06. In 45 minutes: predict one identity/coercion example; trace a closure and detached method; inspect descriptors and holes; implement a small iterable utility; explain an HTTP parsing failure. Require correct mechanics, independent code, and at least four edge tests. Repair the failing lesson before async/framework work.

## Gate B: async and type-safe design

Prerequisites AS01–AS03, FP01, TS01–TS03, SD01, DP01. In 60 minutes: implement bounded concurrent mapping; parse unknown data; design a discriminated state; refactor one effect boundary; test failed work and invalidation. Explain the invariant and one non-use case for your abstraction. No unchecked any at the external boundary.

## Gate C: frontend/backend vertical slice

Prerequisites AG01–AG03, ND01/ND02, PE01/PE02. In 75 minutes: trace the projects from user intent to rendered state; identify a malformed response, stale completion, duplicate write, provider lifetime, and missing production security control. Write one distinguishing test independently. Draw trust/ownership boundaries and disclose unimplemented deployment/persistence/auth pieces.

## Gate D: coding and architecture panel

Prerequisites AL01/AL02, FE01, IV01 and earlier gates. Run a role-specific mock with an unseen algorithm variant, a changed system-design constraint, and a real behavioral story. State preconditions, complexity, failure paths, trade-offs, and honest evidence. Require relevant seven-dimension scores at 2+, repeat weak areas after a delay, and assess projects rather than only definitions.

These are performance criteria for preparation, not guaranteed interview outcomes. Planned modules will add depth beyond these gates.
