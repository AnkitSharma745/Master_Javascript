# 01 — Core Computer Science and Web Fundamentals

This is the foundation for everything else. It explains how code runs on a computer, the basic data structures and Big-O, how the internet moves data, and how a browser turns HTML into pixels.

Frontend, backend and desktop interviews all test these topics. For example, "What happens when you type a URL?", "How does HTTPS work?" and "Reflow vs repaint" come straight from here.

**Start here if:** you are new to programming theory, or you want to fill gaps before the JavaScript section.

## Study order

| # | Topic | What you will learn |
