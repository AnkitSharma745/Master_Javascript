# 05 — Frontend Engineering

This section covers frontend work that applies to every framework: HTML, CSS, the DOM and events, accessibility, performance, component and state design, data fetching, rendering strategies and build tools. It also has a React chapter, because many full-stack and frontend interviews ask about React even when the job uses Angular.

Angular-specific topics live in [06 — Angular 16](../06-angular-16/README.md).

**Before this:** [02 — JavaScript](../02-javascript/README.md) and [browser rendering](../01-cs-and-web-fundamentals/07-browser-architecture-and-rendering.md).
