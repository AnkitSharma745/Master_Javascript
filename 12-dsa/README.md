# 12 — Data Structures and Algorithms

This section prepares you for coding rounds. It is organized by **pattern**, not by random problems. Learn one pattern, see its template, then solve 12–15 classic problems that use it. Once you can recognize the pattern, new problems feel familiar.

Every solution is in **JavaScript**, tested with Node.js, and explained with a dry run, complexity, edge cases, follow-ups, and a short "how to say it in the interview" explanation.

**Before this:** [Data structures and Big-O](../01-cs-and-web-fundamentals/02-data-structures-and-big-o.md) and [Problem solving and complexity](../11-coding-interviews/02-problem-solving-and-complexity.md). For how to talk while you code, see [How to explain technical answers](../11-coding-interviews/01-how-to-explain-technical-answers.md).
